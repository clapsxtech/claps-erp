# Front end: build, structure and asset security

The only front end is the React + Astryx app in `resources/app`. How screens, permissions and tests fit
together is described in [the app README](../resources/app/README.md).

## Build

```sh
npm ci
npm run production        # minified build into public/ui
npm run development       # readable build
npm run watch             # rebuild on change
npm test                  # type-check, build test, deployment tests
```

- **Build output:** `scripts/build-assets.mjs` runs esbuild with the StyleX plugin.
  - It writes hashed, code-split bundles to `public/ui`.
  - It writes `public/ui/manifest.json`, which the host page (`resources/views/app/shell.blade.php`) reads.
- **Styles:** Astryx ships prebuilt CSS. The StyleX plugin compiles only the app's own `stylex.create()` calls.
- **Theme:** the ClapsLearn theme was made with the Astryx theme editor.
  - Editor source is in `themes/claps`.
  - The copy the app imports is in `src/themes/claps`, regenerated by the editor.
  - The container build copies `src/themes` (see `Dockerfile.cloudflare` and `.dockerignore`).
- **Parallel builds:** `UI_OUT=public/ui-x` builds into another folder. Serve it with `APP_UI_DIR=ui-x`.

## Delivery

- **Cloudflare edge:** `scripts/stage-cloudflare-assets.mjs` copies only `public/ui`, `favicon.ico` and
  `robots.txt` into `.cloudflare-assets`. The Worker serves those files at the edge.
- **Laravel container:** every other request, including all pages, which return the host page.
- **What is never staged:** PHP, uploads, source maps, dotfiles and symlinks.
- **Dependencies:** all browser code is bundled from the locked npm dependencies. There are no CDN scripts.
  - The only exception is the error pages (`resources/views/errors/*`), which are self-contained and inline
    their CSS, so they still render if the JavaScript app is broken.

## Host page

- **One shell:** the host page renders for `/app/*`, `/print/*` and every portal page.
- **Session JSON:** it embeds a small JSON session in `<script type="application/json" id="erp-session">`.
  The session holds only what that visitor may see: the user, their teams, and per team the pages, actions
  and exports their role allows.
- **Server-enforced:** the session only decides what to show. Every JSON route is checked again on the server.
